AQUA MIND — النسخة التجريبية للموقع

التشغيل:
1) تأكد إن Node.js موجود على الجهاز.
2) افتح مجلد الموقع، ثم شغّل start.ps1 من PowerShell.
3) هيفتح الموقع تلقائيًا على http://localhost:4173

النسخة تعمل دون مفتاح ذكاء اصطناعي: فيها أسئلة متابعة موجهة، وبتحاول تجيب أبحاثًا فعلية حديثة عبر OpenAlex. لو خدمة البحث غير متاحة، الموقع يوضح ذلك.

لتفعيل تحليل AI والبحث المباشر على الويب:
- جهّز مفتاح OpenAI API خاصًا بك.
- في نافذة PowerShell نفسها، قبل تشغيل الموقع، نفّذ:
  $env:OPENAI_API_KEY="ضع_مفتاحك_هنا"
  $env:OPENAI_MODEL="gpt-4.1-mini"
- ثم شغّل: node .\server.mjs
- لا تضع المفتاح في ملفات الواجهة أو تشاركه علنًا.

ملاحظة: الواجهة الحالية نسخة أولية للعرض والتطوير، ومخرجاتها لا تُعد تشخيصًا أو بديلًا عن جهة مياه محلية أو مختص.
